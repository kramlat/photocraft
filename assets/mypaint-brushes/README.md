# MyPaint brushes

The default brush set of MyPaint (`mypaint-brushes` 2.0.2, https://github.com/mypaint/mypaint-brushes),
the `.myb` files and their `<name>_prev.png` previews (128×128, drawn by the brush authors, shown in the
MyPaint Brushes panel). The set is dedicated to the
public domain under CC0 1.0, see `LICENSE-CC0.txt`; the authors are named in each file's
`comment` and `group`. They paint through PhotoCraft's MyPaint engine
(`crates/paint/src/mypaint`).
